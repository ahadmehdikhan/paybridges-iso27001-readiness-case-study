# paybridges-iso27001-readiness-case-study
End-to-end ISO 27001:2022 ISMS implementation and audit case study for PayBridges (cloud-native SaaS platform). Features ISO 27005 risk register, Statement of Applicability (SoA) mapped to SOC 2 TSC, Test of Design (ToD) &amp; Operating Effectiveness (ToE) workpapers, policies, and CAPA remediation plans.
